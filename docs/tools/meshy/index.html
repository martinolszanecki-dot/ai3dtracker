Approx. cost per model: ≈$0.20 (Pro: $20 / up to 100 assets, per Meshy's own figure)

Free tier: Yes – 100 credits/month, 1 concurrent task, low priority, no card

Output & license

Inputs: Text, image, multi-view image

Export formats: FBX, OBJ, USDZ, GLB, STL, BLEND

Commercial license: Paid: you own assets. Free: CC BY 4.0 (commercial use with attribution).

Current model version: Meshy 7.1 (API 'latest'); Meshy 6 and Meshy 6 Lite still offered; texture model Meshy N1 (stylized/low-poly, added Oct 2026); Smart Topology model Meshy T2.5 (added Oct 15, 2026) replaced Meshy T1 / 'lowpoly', which was retired on Oct 30, 2026 (every T1 API request returns 400 from Nov 30, 2026)

Printability: STL and 3MF export; Analyze/Repair Printability, Multi-Color Print, Auto Split and (from Nov 5, 2026) Relief for bas-relief prints; marketed to 3D-printing hobbyists

Features

  • Texturing: Yes (AI texturing, upload FBX/OBJ/STL/GLTF/GLB); texture models Meshy 7, Meshy 6 Lite and Meshy N1 (stylized/low-poly base color, all plans incl. Free)
  • Rigging/animation: Yes – auto-rigging (5 credits via API); animation with 600+ motions on paid plans
  • Retopology: Yes – Remesh (5 credits) and Smart Topology models Meshy T2/T2.5 (triangle-only, 100–30,000 faces on T2.5)

DCC bridge: Roblox, Blender, Godot, Unity, Unreal, Maya, 3ds Max. API available. 50% off first month for new users. New Oct 16, 2026: Meshy Edit – change only a selected part of a model with text or up to 5 reference images (20 credits per edit, refunded on failure). meshy-5 retired in the API on Oct 10, 2026; the 'lowpoly' model type was retired Oct 30, 2026. API changelog (checked 2026-10-26): Oct 19 – Keychain/Fridge Magnet export_resolution capped at 512; Oct 21 – X-Meshy-Metadata request header (Studio/Enterprise); Oct 23 – texture_image_url deprecated on Rigging. Plan prices unchanged on 2026-10-26. Re-checked 2026-11-02: plan prices unchanged. API changelog: Oct 26 – new Deprecations page listing every model's lifecycle and retirement date; Oct 30 – Meshy T1 ('lowpoly' / 'meshy-t1') retired on Text/Image to 3D, replaced by 'smart-topology' with 'meshy-t2.5'; Auto Split gains keep_texture (split parts keep their texture, still 10 credits). Re-checked 2026-11-09: plan prices unchanged; Ultra confirmed at $100/mo (8,000 credits, up to 800 assets) and Studio at $70/mo plus $10/mo per extra seat on the official pricing page; new users get 50% off the first month on monthly plans. Web app changelog (October): Meshy N1 texture model for stylized and low-poly game assets, available on all plans including Free. API changelog: Nov 2 – Meshy N1 on Retexture (2K base color from 1–4 reference images, 10 credits); Nov 3 – texture_model parameter on Image to 3D / Multi-Image to 3D and Meshy N1 on Text to 3D refine; Nov 5 – new Relief API (one photo to a bas-relief GLB/STL plus a 16-bit depth map for 3D printing, laser engraving and CNC, 20 credits). From Nov 30, 2026 every Meshy T1 request returns 400.
